# Storyboard Template

> 用于把完整故事拆成连续视觉镜头。

建议在完成以下文件之后再使用本模板：

```text
story_idea_template.md
↓
story_bible_template.md
↓
storyboard_template.md
```

这一阶段不再解决“故事讲什么”，而是解决：

> **观众究竟会一张一张看到什么？**

# 20. 普通生活镜头检查

- [ ] 建立主角身份
- [ ] 建立日常路线
- [ ] 建立主要地点
- [ ] 建立人物关系
- [ ] 让观众相信世界原本正常
- [ ] 普通镜头不过多
- [ ] 至少有一个细节可成为后续伏笔

---

# 21. 第一次异常检查

- [ ] 足够简单
- [ ] 一眼能理解
- [ ] 暂时可以合理解释
- [ ] 有强视觉记忆点
- [ ] 不直接暴露最终真相

---

# 22. 中段检查

- [ ] 每 2—4 张有新信息
- [ ] 不是不断重复“很奇怪”
- [ ] 出现视觉证据
- [ ] 主角从被动变主动
- [ ] 危险 / 个人关联增加
- [ ] 仍围绕核心谜题

---

# 23. 真相前检查

- [ ] 至少出现过 3 个以上相关证据
- [ ] 观众理论上可以猜到部分答案
- [ ] 真相不是凭空出现
- [ ] 关键人物 / 道具已经提前建立
- [ ] 最终反转可以解释前面的异常

# 30. 完成分镜后的最终检查

## 故事
- [ ] 第一张能进入故事
- [ ] 前几张足够建立现实
- [ ] 核心谜题明确
- [ ] 异常逐级升级
- [ ] 主角行动合理
- [ ] 中段不拖沓
- [ ] 真相提前埋过证据
- [ ] 结尾回收主要问题

## 镜头
- [ ] 每张图都有明确作用
- [ ] 不存在大量重复镜头
- [ ] 不连续使用相同角度
- [ ] 第一 / 第三视角切换合理
- [ ] 有关键视觉图腾

## 连续性
- [ ] 人物一致
- [ ] 服装一致
- [ ] 地点一致
- [ ] 道具一致
- [ ] 天气合理
- [ ] 时间合理
