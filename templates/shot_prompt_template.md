# Shot Prompt Template / 单镜头提示词模板

> 把已经确定的分镜，转成当前这一张图可以执行的画面要求。

先使用快速版；遇到人物识别、复杂空间、屏幕文字或局部修图，再补充对应模块。提示词不需要把整部故事重新讲一遍，重点是说清本镜不能错的内容。

## 使用方式

- 输入：当前镜头的分镜、相关故事设定，以及实际可提供的参考图。
- 输出：一份可以提交给图像工具的生成或修改描述，以及本次输出的验收条件。
- 可在作品目录中按镜头保存，例如 `prompts/S001.md`；也可集中记录，但应能找到每个镜头的实际提示词和参考文件。
- 本模板适用于静态图像，不预设某个模型的参数、语法或能力。工具支持哪些尺寸、参考图和编辑方式，以实际使用界面为准。
- 分镜仍有影响画面的未决问题时，先明确选择。可以让 AI 提出方案，但采用哪种剧情和设定，应在生成前确认并记入相应文件。

## 一、快速版：一张图需要交代什么

### 制作记录

```text
项目 / 镜头 ID：
操作：新图生成 / 基于已有图修改
分镜与设定版本：
本镜作用：
参考图及各自用途（没有则写无）：
```

### 可直接整理成提示词的内容

```text
画面形式、风格与目标比例：
视角归属、观察位置与朝向：
主要主体及选定的动作瞬间：
地点与必要空间关系：
时段、天气与光源：
必须看清的细节：
需要延续的外观与状态：
本镜允许的变化：
暂不展示的内容与具体遮挡方式：
需要准确出现的文字 / 后期处理（没有则写无）：
针对本镜的必要限制：
```

将填写结果合并为一段或几段清楚的描述，删除空项、重复要求和与当前画面无关的背景故事。共同设定只抽取本镜需要的部分。

### 提交前的验收目标

```text
生成后必须检查的可见条件：
1.
2.
3.
```

条目数量按需要增减。写成可以核对的内容，例如“照片中的蓝色袖口能辨认”，不要只写“氛围到位”或“观众看懂真相”。

## 二、把叙事要求翻译成画面

| 分镜中的任务         | 还需要补充的画面要求                           |
| -------------------- | ---------------------------------------------- |
| 发现有人来过         | 被移动的物件、留下的痕迹，以及与前镜的可见差异 |
| 认出同一件道具       | 与参考图对应的独特标记、颜色、结构及其可见位置 |
| 暂时不知道照片里是谁 | 照片的朝向、被遮挡区域和仍允许露出的部分       |
| 感到不安             | 具体的人物行为、距离、环境变化或信息冲突       |
| 已经过了很久         | 本镜可呈现的状态变化，或明确安排的日期、配文   |

后台事实不必全部写进生成描述。尤其是尚不能露面的身份、人物或物件，只保留控制当前画面所需的限制，避免无关故事内容干扰画面。

“只露出照片右下角，主体被被子覆盖”比“显示 20% 的线索”更明确。若关键结论只能靠正文或旁白说明，应在分镜中安排这些内容，不能靠提示词里的解释替代成图证据。

## 三、按需补充的模块

### A. 参考图：分别说明采用什么

| 参考编号 | 实际文件 / 版本 | 本次用于固定什么     | 不采用或需要改变的部分 |
| -------- | --------------- | -------------------- | ---------------------- |
| R1       | ［文件］        | ［人物外貌、服装等］ | ［姿态、背景等］       |
| R2       | ［文件］        | ［场景布局、道具等］ | ［光线、错误细节等］   |

提交时确认参考图已实际附上，并使“参考图 1”等称呼与附件顺序一致。提示词中写了文件名，不代表图像工具已经收到文件。

```text
参考图之间有无冲突：
冲突时采用哪个具体特征：
本镜相对参考图需要改变什么：
```

“保持上一张一致”应指向明确的文件和特征，例如“沿用 R1 中桌腿的形状与桌面缺口”。参考图只用于固定某件衣服时，不应把背景和机位也一并照搬。

角色、道具和场景参考存在冲突时，先在故事设定中确定采用版本，再生成。不要要求模型同时满足互相矛盾的参考。

### B. 视角、动作与构图

```text
谁在看：
站立 / 坐下 / 蹲下等姿态：
观察高度、朝向与主体距离：
这是角色所见，还是故事中真实拍摄的影像：
允许出现的身体部位与反射：
选定的单一动作瞬间：
主要阅读对象及其位置：
必要的前景、中景、背景：
```

第一视角不要求每张都有手或脚。镜头朝向和身体部位应符合姿态；不需要为了强调 POV 强行添加双手。

一张静态图不同时表现“开门、走入、转身、拿起物件”四个时刻。选择一个瞬间，或回到分镜拆开。需要出现动作结果时，也应说明当前姿态，而不是只描述动作过程。

空间的左右应有观察方向，例如“从入口向内看，桌子位于左墙边”。允许画外物件不入镜，不等于允许它在故事空间中消失。

### C. 人物、地点与道具连续性

```text
引用的设定 ID：
本镜可见的固定识别特征：
当前服装、身体与道具状态：
必须保持的布局关系：
上一镜发生的变化：
本镜新增的变化及原因：
```

同一个人物可以换装，同一个地点可以改变光线，前提是与时间线相符。提示词应分别写清稳定特征和当前状态，避免把“保持一致”变成所有画面都不能变化。

同款物件不自动等于同一件。剧情依赖物件身份时，要把独特标记写成可见要求，并在生成后对照检查。

### D. 光线、风格与清晰度

```text
采用的视觉风格：
实际光源及方向：
曝光、色彩和景深要求：
允许模糊、噪点或遮挡的区域：
必须清晰可辨的区域：
```

手机随拍只是可选风格。若采用，可以用自然光、适度噪点和普通构图说明质感，不必把偏斜、失焦、过曝、运动模糊全部叠加。

暗处物件应由环境中的光源照亮，除非设定允许，不让物件自行发光。关键线索的可读性优先于装饰性的模糊效果。

### E. 文字、手机屏幕与照片

```text
承载物及外观参考：
必须准确呈现的原文：
文字顺序、位置与大小：
必须可读 / 可以模糊的区域：
直接生成还是后期排字、合成：
合成需要预留的空间与透视：
```

聊天画面需要核对头像、备注与公开昵称、消息方向、日期和时间，以及具体界面状态。“没有回复”不能代替“消息被拒收”；如果剧情依赖某种状态，必须安排可见依据。

文字直接生成后逐字检查。若选择后期添加，要在记录中保留“待合成”状态，不能把空白屏幕视作完成。合成后同时检查透视、遮挡和缩小展示时的可读性。

老照片应区分两层：当前镜头怎样看到照片，以及照片内部描绘什么。年代不自动决定黑白、泛黄或严重破损；根据作品设定选择这些特征。

### F. 比例与输出设置

```text
目标比例：
工具中实际选择的尺寸或比例设置：
本次输出实际宽 × 高（生成后记录）：
是否需要裁切、扩图或其他处理：
处理后必须保留的主体与线索：
```

提示词中的比例要求不能替代实际输出核对。工具支持独立尺寸设置时同时检查设置；输出不符时根据构图决定处理方式，不直接拉伸，也不默认裁切后线索仍然完整。

### G. 限制项与冲突检查

只保留当前镜头真正需要的限制，并写明保留内容。例如“墙上照片不进入本镜，但桌上的相框保留”，比“不要任何照片”更符合具体分镜。

常见冲突包括：

- 同时要求照片人物可辨认、又要求照片完全模糊。
- 要求全景展示房间、又要求远处小字清楚可读，却没有安排距离或额外特写。
- 要求与原图全部不变、同时更换机位和主体姿态。
- 一方面要求删除所有文字，另一方面依赖聊天内容推进剧情。

发现冲突时先调整要求。限制项可写入普通描述；只有实际工具提供对应功能时，才使用独立负面提示词等设置，不假设所有工具采用相同语法。

## 四、最终生成描述

只保留一份当前准备提交的版本，不必强制填写草稿、精简稿和最终稿三套重复内容。实际提交后保留原文，修改时新增版本。

```text
［画面形式、视觉风格与比例］。
［视角归属、位置、朝向］，画面呈现［主体与选定瞬间］。
［地点与必要空间关系］。
［关键物件和可见细节］。
［光源、清晰度和构图要求］。
沿用［参考编号］中的［具体特征］，本次改变［具体部分］。
保留［必要内容］，本镜不展示［具体内容］。
［必要文字及其制作方式］。
```

若没有参考图，删除相关句子，并直接写清必要特征。不把空模板或未解决的多个选项一并提交。

### 填写示例：失物招领处找回包

以下是独立教学示例，沿用分镜模板中的帆布包情节，不属于仓库现有作品。示例假定已提供包的参考图 R1。

```text
9:16 竖屏，普通手机摄影质感。
主角站在失物招领柜台前的第一视角，视线略向下。
一个帆布包已经放在柜台上，正面朝向主角，占据画面中下部。
包的外观沿用参考图 R1，蓝色方形补丁和缺了一角的金属扣均清晰可见。
工作人员站在柜台后，手刚从包旁收回，人物不是画面阅读重点。
室内普通照明，柜台和包清晰，背景简洁，不添加其他相似的包。
不显示主角的手脚，不在包上增加新的文字或图案。
```

这段描述负责表现包的身份与当前瞬间。地点如何被观众认出，仍需落实分镜中安排的招领标识或配文；不能只因提示词写了“失物招领处”就认为地点已被解释。

## 五、生成后检查与局部修改

### 先检查本镜是否完成任务

- [ ] 必须可见的主体、标记和文字实际可辨认。
- [ ] 人物、物件与场景符合本次采用的参考和状态。
- [ ] 视角、动作瞬间及空间关系成立。
- [ ] 没有提前显示暂不揭示的信息。
- [ ] 实际比例符合要求，或有明确的后续处理方案。
- [ ] 后期文字、界面和其他待办已完成，或仍明确标为待办。

具体问题写入作品的连续性记录；本文件保留本次修改所需的摘要和链接即可。

### 局部修改模板

```text
镜头 ID / 本次修改版本：
待修改的原图文件：
问题：
受影响的叙事信息：
修改区域或对象：
需要改成什么：
必须保留的具体特征：
允许随修改发生的必要变化：
完成后需要重新核对的项目：
```

修改描述示例：

```text
以本次附上的柜台图片为底图。
只修正帆布包的金属扣件，使其缺角的位置和形状与 R1 一致。
保留包的蓝色补丁、柜台位置、工作人员姿态、机位、光线和画面比例。
扣件周围的局部阴影可随形状调整，不修改其他区域。
```

局部修改是目标，不是结果保证。输出后同时检查目标是否修好，以及原本正确的内容是否漂移。若错误涉及整体透视、复杂动作或多处依赖，先评估重新构图或生成，避免反复局部修改造成更多冲突。

## 六、保留实际制作记录

```text
镜头 ID / 提示词版本：
操作类型：
实际提交的提示词：
实际附上的参考图及顺序：
实际使用的工具 / 模型（能确认的范围）：
实际设置（仅记录工具提供且本次使用的参数）：
输出文件：
状态：未生成 / 待核对 / 需修改 / 已通过
待完成的后期项目：
检查依据 / 修订记录链接：
最终采用文件（确认后填写）：
```

不要补写未记录的种子、模型版本或参数，也不要把事后整理的提示词称为原始生成记录。即使保留完整记录，也应以实际输出检查为准，不承诺不同生成次数会得到完全相同的图片。

完成后更新分镜中的采用文件与状态；如果修改改变了共用设定，同步更新设定文件及受影响镜头。
