# Continuity Checklist / 连续性检查清单

> 对照设定、分镜和实际图片，检查故事是否连得上、关键内容是否看得清，并记录问题如何处理。

先用快速检查定位问题，再展开适用的专项。没有出现的对象和不适用的项目无需逐项检查，也不要为了勾满清单给画面添加内容。

## 使用方式

- 输入：本次实际采用的图片版本、对应分镜、故事设定和必要参考图。
- 输出：本次检查结论、待处理问题和复查结果，可保存到作品目录的 `continuity_notes.md`。
- 每张图先检查关键叙事信息；完成一个连续动作、一个场景或一组相互依赖的镜头后，再检查前后衔接。批次大小按复杂程度决定。
- 修改图片、替换参考或更改设定后，复查受到影响的部分；发布前检查最终采用文件及展示顺序。
- 设定说明作者希望什么成立，图片说明实际呈现了什么。两者不一致时记录偏差，不把设定文字当成图片已经合格的证据。

## 一、快速检查与结果记录

### 检查范围

```text
项目：
检查日期 / 检查人：
镜头范围与实际图片文件：
分镜版本：
设定版本：
采用的参考文件：
本次检查目标：单图 / 连续段落 / 修改复查 / 最终展示
```

### 快速检查

- [ ] 使用了正确的图片版本、顺序与文件映射。
- [ ] 本镜需要传达的主体、动作或线索实际可见。
- [ ] 人物、道具和地点能按剧情需要被识别。
- [ ] 视角、空间关系、时间与状态变化可以衔接。
- [ ] 必要文字和界面状态准确且可读。
- [ ] 暂不揭示的内容没有意外露出。
- [ ] 实际尺寸、比例及裁切范围符合本次用途。
- [ ] 当前修改没有破坏原本正确的关键内容。

勾选表示在注明的范围内完成核对且符合要求。未勾选可能是未检查、发现问题或不适用，不能单靠空框表达结论；在结果表中区分。

| 镜头 / 文件版本 | 检查项   | 检查状态 | 实际观察与依据               | 问题 ID / 备注 |
| --------------- | -------- | -------- | ---------------------------- | -------------- |
| ［镜头 / 文件］ | ［项目］ | 待核对   | ［看到什么、与哪份参考比较］ | ［ID 或无］    |

## 二、状态与优先级

### 检查状态

| 状态     | 含义                                     |
| -------- | ---------------------------------------- |
| 待核对   | 尚未完成本项检查                         |
| 符合     | 指定图片版本在本项上满足要求             |
| 有偏差   | 已发现与要求不一致，需记录影响和处理方式 |
| 无法判断 | 清晰度、参考资料或设定不足，暂不能下结论 |
| 不适用   | 本镜不涉及这项要求，注明必要原因         |

“符合”不能推广到未检查的镜头或新版本。作者确认设定也不等于成图检查通过；不使用一个 `LOCKED` 同时表达这两件事。

### 按实际影响确定优先级

| 优先级       | 判断依据                                                     | 处理方向                                                     |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 阻断当前用途 | 核心结论无法成立、对象认错、关键内容提前揭露，或不满足明确交付要求 | 解决后才能通过对应阶段检查；可能需要修图、后期处理或调整分镜 |
| 重要         | 不一定破坏主线，但明显影响识别、空间理解或连续性             | 明确处理方案；保留时记录理由和影响                           |
| 次要         | 不影响关键理解的局部差异或装饰性问题                         | 根据用途决定修正或接受，并记录决定                           |

不要只按错误类别定级。背景路人的变化可能合理；关键照片中的人物变化则可能阻断理解。比例不符也要看交付要求和可修复性，不能直接等同于整图重做。

## 三、按需检查的专项

### A. 文件、尺寸与展示

- [ ] 镜头 ID、展示顺序与实际文件一一对应，没有误用旧图或漏图。
- [ ] 扩展名与真实文件匹配，文档引用指向当前采用文件。
- [ ] 已读取实际宽高并核对比例，没有只依据提示词判断。
- [ ] 裁切、扩图或缩放后，主体和必要线索仍保留。
- [ ] 在预期展示大小下，关键文字、照片和标记仍可辨认。

若作品配有正文、旁白或字幕，分别检查图片本身和完整展示。只能依靠配文成立的结论，不要写成“画面独立说明”。

### B. 人物身份、服装与状态

- [ ] 当前出场人物及数量符合分镜，没有混淆角色。
- [ ] 可见的脸、发型、体型或其他识别特征符合采用的参考。
- [ ] 服装、鞋和配饰符合当前时间段，换装有合理依据。
- [ ] 伤势、泥污、淋湿、破损等状态延续，恢复或变化有依据。
- [ ] 人物动作、情绪与当前经历相容。

只核对可见且需要固定的部分。第一视角未露脸时，脸部检查可标“不适用”；不应为了检查脸而要求额外露脸。

服装、体型或表情不能单独证明人物的身份关系、职业或行为动机。若剧情依赖这些结论，另查信息依据。

### C. 视角、人体与动作

- [ ] 视点属于分镜指定的角色或叙述位置，高度与姿态相符。
- [ ] 入镜的手脚、身体边缘与反射位置合理，没有肢体融合或穿插。
- [ ] 动作符合当前持物、空间和身体状态。
- [ ] 静态画面呈现的瞬间清楚，没有被要求同时完成多个时刻的动作。
- [ ] 视角切换符合本作品规则，并能被观众理解。

第一视角可以完全不出现身体。第三视角能否展示主角不知道的内容，取决于作品的叙述规则，不一概禁止。

采用“角色所见”的形式时，不必推定角色一直拿手机拍摄；若设定为故事内实际录像，再检查设备、持握与拍摄行为。

### D. 地点、机位与空间

- [ ] 同一地点的固定地标、建筑结构、道路和主要陈设可以对应。
- [ ] 当前机位和朝向与布局相容，人物路线和出入口可实现。
- [ ] 固定物件没有无故移动、复制或消失。
- [ ] 门窗、灯具、入口等没有未经设计的新增或替换。
- [ ] 已损坏、被移动或被打开的物件状态延续。

描述左右时注明观察方向。反向机位导致画面左右变化，不等于布局错误；物件位于画外或被遮挡，也不等于消失。无法对应时先核对机位，再决定是否修图。

```text
参考镜头与观察方向：
当前镜头与观察方向：
可对应的固定元素：
确认的偏差 / 尚不能判断的部分：
```

### E. 道具、车辆与重复对象

- [ ] 当前对象的结构、颜色、材质、尺度与必要标记符合设定。
- [ ] 所属人物、持有人和位置符合事件顺序。
- [ ] 打开、破损、空满等状态变化有依据。
- [ ] 剧情需要认出同一对象时，相关镜头提供了足够可见的识别特征。

同款不一定是同一件。设定已确定为同一道具，但成图特征不一致时，应保留设定并记录画面偏差，再决定修正方案。

车辆可在本项核对外观、内饰、车况与必要编号，不需要另建重复的整套检查表。

### F. 手机、文字、文件与照片

- [ ] 手机外观、屏幕开孔、手机壳及必要界面元素符合采用参考。
- [ ] 头像、公开昵称和联系人备注对应正确；名称不同有明确设定依据。
- [ ] 聊天消息原文、发送方向和顺序正确。
- [ ] 日期、时间及“昨天”等相对时间与故事时间线相容。
- [ ] 界面实际呈现了剧情需要的状态，没有把“未回复”当作“被拉黑”。
- [ ] 关键文件、编号、照片身份和物理外观保持一致。
- [ ] 必须读清的内容可以读清，需要遮挡的内容没有过早暴露。
- [ ] 后期文字或合成已完成，并符合透视、遮挡和展示大小。

老照片不必一律黑白或泛黄，按作品设定检查。照片中的人物需要被认出时，记录具体识别依据；不能因为作者知道是谁，就认定观众已经识别。

有意设计的证件、相框或标识应保留，只处理错误或未经设计且影响故事的新增内容。

### G. 时间、天气与移动

- [ ] 事件先后、时间间隔和回忆段落符合分镜。
- [ ] 可见日期、人物年龄和时代元素没有冲突。
- [ ] 昼夜、光源、天气、地面及衣物状态相容。
- [ ] 移动路线和经过时间在故事规则内成立。
- [ ] 跳过路程或时间后，仍有足够依据理解转场。

没有精确日期依据时，不强行推算具体年月日。天气变化不必逐镜解释，但不应与紧接发生的行动和状态冲突。

### H. 因果、信息与揭示边界

- [ ] 角色的重要行动符合其动机和当时掌握的信息。
- [ ] 后续结论所依赖的线索确实出现在采用的图片或正文中。
- [ ] 画面直接显示的事实与观众可能的推断被分开记录。
- [ ] 允许提前出现的局部伏笔保留，暂不揭示的身份或关系未意外露出。
- [ ] 结尾回应了主要目标、关系或问题；留白与遗漏有明确区别。

| 计划支持的结论 | 实际可见依据及镜头 | 还依赖什么       | 本次判断                                |
| -------------- | ------------------ | ---------------- | --------------------------------------- |
| ［结论］       | ［具体细节］       | ［前文、配文等］ | ［支持 / 部分支持 / 不支持 / 无法判断］ |

不用信息释放百分比替代检查。悬念可以提前揭示，情绪可以缓和，证据可以直接说明事实；是否合适按本作品分镜判断，不要求所有故事持续升级异常。

### I. 风格、物理与特殊规则

- [ ] 画面符合项目选择的风格，连续段落没有无意的明显风格跳变。
- [ ] 光源、阴影、反射、支撑关系和物体尺度符合本作品规则。
- [ ] 清晰度、噪点与模糊没有妨碍关键内容阅读。
- [ ] 若有异常生物、科幻装置或超自然效果，其形态与能力符合已确定规则。

“AI 味重”不足以形成修改要求，应指出具体问题，如皮肤纹理不自然、阴影方向冲突或背景物件融合。电影感、对称构图和整洁房间本身不构成错误；选择手机随拍风格，也不要求每张都出现噪点和模糊。

### J. 段落节奏与重复

```text
本次检查段落：
各镜头的作用：
重复构图或内容的目的：
转场是否能理解：
需要停留的情绪是否得到空间：
建议保留、合并或调整的镜头及原因：
```

同角度可用于比较变化，日常镜头可用于建立生活感。判断是否重复时看叙事作用，不规定每三张必须推进、每五张必须增加一个问题。

若做过观众阅读测试，记录测试版本、观看条件和具体反馈；没有测试时，只写作者或检查者判断，不声称观众必然理解。

## 四、问题记录：从发现到复查

每个需要跟踪的问题建立一个 ID，避免同一个错误在多份文件中出现互相冲突的状态。

```text
问题 ID：
涉及镜头 / 当前图片版本：
问题类别与优先级：
检查依据（设定、分镜、参考图）：
实际观察：
对剧情或展示的影响：
处理决定：修图 / 后期处理 / 重生成 / 调整分镜或设定 / 保留
本次只改什么：
必须保留什么：
受影响的其他镜头或文档：
处理状态：待决定 / 待修改 / 待复查 / 已修正 / 接受保留
新文件或文档版本：
复查内容与结果：
处理或保留理由：
```

“已修正”必须有指定新版本的复查依据。只有修改建议、提示词或已生成的新图时，分别记录为待修改或待复查。

接受保留的偏差仍记录为偏差，不改写成“从未有问题”。它是否影响下一阶段，应在阶段结论中说明；阻断当前用途的问题不能仅通过改状态解除。

### 处理示例（独立教学示例）

```text
问题 ID：C001
涉及镜头：S001 与 S003
检查依据：设定要求两镜出现同一只带蓝色补丁、缺角金属扣的帆布包。
实际观察：S003 的补丁相符，但扣件完整，没有缺角。
影响：削弱“找回同一只包”的识别依据。
优先级：重要；本例仍有补丁可供识别，尚未判定核心结论完全失效。
处理决定：局部修改 S003 的扣件，对照 S001 保持缺角形状一致。
必须保留：包的补丁、柜台、人物姿态、机位与光线。
处理状态：待修改。
新文件 / 复查结果：暂无，不能标为已修正。
```

优先级随实际画面和故事需要判断；如果补丁也不可辨，导致包无法识别，应重新评估影响。

## 五、复查与阶段结论

### 修改后复查

- [ ] 目标问题在新版本中确实得到解决。
- [ ] 原本正确的关键特征没有漂移。
- [ ] 与前后相关镜头仍能衔接。
- [ ] 尺寸、裁切和后期文字仍符合要求。
- [ ] 分镜映射、文档图片链接和采用文件已更新。
- [ ] 若调整了共用设定，已检查受到影响的其他镜头。

优先修正局部问题；如果修改涉及整体空间、动作或多镜依赖，再评估重新生成或调整分镜。检查范围随影响扩大，不必为一个局部变化无条件重查全部内容。

### 本次结论

```text
检查范围 / 采用版本：
已完成的检查：
未完成或无法判断的项目：
仍阻断当前用途的问题：
其他待处理问题：
已接受保留的偏差及理由：
下一阶段：继续生成 / 后期处理 / 剪辑排版 / 发布前检查
本范围是否可进入上述阶段：是 / 否
依据与下一步动作：
```

能进入后期处理不等于可以发布；某一段落通过也不等于整部作品通过。阶段结论只覆盖列出的文件和检查范围。

最终展示前，至少确认当前采用文件、顺序、必要文字与链接正确，关键因果和身份识别可成立，所有阻断发布的问题已经解决。需要保留的非阻断偏差应有明确记录。

## 六、与其他文件的衔接

| 发现的问题                           | 主要回到哪里处理                                             |
| ------------------------------------ | ------------------------------------------------------------ |
| 动机、因果或结局无法成立             | [story_idea_template.md](story_idea_template.md) 对应的构思文件 |
| 共用人物、道具、地点或规则不明确     | [story_bible_template.md](story_bible_template.md) 对应的设定文件 |
| 画面任务、顺序或转场不足             | [storyboard_template.md](storyboard_template.md) 对应的分镜文件 |
| 生成描述、参考图或局部修改要求不准确 | [shot_prompt_template.md](shot_prompt_template.md) 对应的制作记录 |
| 已发现的成图偏差及复查结果           | 作品的 `continuity_notes.md`                                 |

可参考[《郊区网恋》的连续性记录](../examples/suburban_online_romance/continuity_notes.md)，了解如何同时保留作者设定、实际画面观察和待修订事项。记录了问题，并不意味着对应图片已经修好。
