# 16. 快速自检

- [ ] 能不能用一句话说明这个故事为什么有意思？
- [ ] 有没有一个非常明确的核心谜题？
- [ ] 我自己知不知道最终真相？
- [ ] 真相会不会自然留下视觉证据？
- [ ] 前面有没有足够普通的现实生活？
- [ ] 异常有没有逐步升级？
- [ ] 每一次升级是否真的比上一次更严重？
- [ ] 有没有至少 5 个可以被画出来的证据？
- [ ] 真相揭开以后，前面的某些画面会不会产生新的含义？
- [ ] 有没有一个值得被观众记住的视觉图腾？
- [ ] 主角为什么会继续调查，而不是直接离开？
- [ ] 故事结尾有没有解决最重要的问题？
- [ ] 结尾有没有留下适量的未知？
- [ ] 这个故事是否适合用视觉来讲，而不是必须依赖大量对白？
