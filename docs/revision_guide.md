# 图片修订指南：发现问题后，怎样改得清楚

> 先确定哪里影响了故事，再选择修图、后期处理、重新生成或修改分镜。改完后核对实际结果，才算完成。

本指南适合已经有图片、却不知道怎样修正的新手。[连续性检查清单](../templates/continuity_checklist.md)帮助发现和记录问题；这里重点讲发现以后怎样处理。

示例包含《郊区网恋》的制作问题，涉及后半段线索和结局剧透。修改描述均为教学整理，不是原始提示词，也不代表修复已经执行。工具是否支持局部编辑、扩图或参考图，应以实际功能为准。

## 1. 先把“这张不对”写成具体问题

不要急着把整张图片重新生成。先记录四件事：

```text
当前图片与版本：
实际看到的问题：
它与哪份设定、分镜或参考不一致：
它影响了观众理解什么：
```

| 模糊反馈   | 可以执行的反馈                                             |
| ---------- | ---------------------------------------------------------- |
| 人物不像了 | 与采用参考相比，脸型和发际线改变，可能被认成另一个人       |
| 场景不对   | 入口从没有门板的开口变成木门，与前一镜冲突                 |
| 太假了     | 夜间桌面自己发光，但场景只有道路路灯                       |
| 这张看不懂 | 照片很清楚，但此前没有主角识别依据，观众不知道照片拍的是谁 |
| 比例错了   | 实际输出为 3:4，目标为 9:16，左右边缘又有关键线索          |

如果说不清差异，可以先请能看图的工具比较图片和参考，只描述观察结果。看不清的部分标“无法判断”，不要先补出一个错误原因。

### 先排除三种误判

- **换机位：**反向观看会改变画面左右，不一定改变真实布局。
- **被遮挡或在画外：**当前看不到物件，不等于它在故事里消失。
- **有依据的变化：**换装、天气变化或道具被移动，可能符合时间线。

只有确认与当前采用的要求不符，才进入修改。

## 2. 选择修正方式

| 问题情况                         | 优先考虑                   | 需要注意                           |
| -------------------------------- | -------------------------- | ---------------------------------- |
| 构图正确，某件物品或局部特征错误 | 局部编辑                   | 指明底图、区域、目标与保留内容     |
| 文字需要准确，图片空间已合适     | 后期排字或合成             | 检查透视、遮挡、清晰度和界面顺序   |
| 比例不符，边缘没有必要内容       | 裁切并重新构图             | 先预览裁切范围，不只看数值         |
| 比例不符，需要保留两侧内容       | 扩图或重新生成             | 新增区域也要检查空间、光线与物件   |
| 人体动作或整体透视不成立         | 重新设计构图或生成         | 先修正动作描述，避免重做同一个错误 |
| 单张正确，前后仍无法理解         | 调整分镜、补过渡或必要叙述 | 不要把叙事缺口当作细节修图问题     |
| 次要背景差异，不影响当前用途     | 接受保留                   | 记录理由，不把所有差异都当成故障   |

这些是判断起点，不是工具效果保证。局部编辑若反复破坏正确区域，应回到最近可靠的版本，重新选择方案。

### 决定先改哪一个

优先处理阻断当前用途的问题，例如关键身份无法识别、因果断裂或提前泄露核心信息；随后处理明显干扰连续性的变化；最后考虑不影响理解的装饰性差异。

不按类别机械定级。同样是衣服变化，普通跨日换装可能合理，承担身份揭示的礼物裙装变化则可能影响结尾。

## 3. 写一份明确的修改要求

下面这段可以复制使用，删去不适用项：

```text
以附图［编号 / 版本］为底图。
当前问题：［可见差异］。
修改对象或区域：［具体位置］。
改成：［目标外观、状态或文字］。
参考依据：［实际附上的参考及采用特征］。
必须保留：［已正确的人物、构图、空间、光线等］。
允许的关联变化：［必要阴影、反射或遮挡调整］。
输出要求：［比例、尺寸或其他实际需要］。
```

不要一面要求“全部像素不变”，一面要求换机位或改变人物姿态。明确哪些局部变化是完成修正所必需的。

附件顺序应与描述一致，待修改底图和身份参考要分别说明。只写文件路径不等于工具已经收到文件。

## 4. 常见问题怎样处理

### A. 人物换脸、发型或服装漂移

**先查：**是不是采用了错误版本？参考是否看得清所需特征？光线和朝向能否解释差异？该时间段是否允许换装？

若确实漂移，选清晰的已采用参考，分别说明身份、服装和姿态来源，不把参考图的背景也一并复制。

```text
附图 1 是待修图片，附图 2 用于固定人物外貌。
修正附图 1 中人物的脸型、发际线和发型，使其符合附图 2。
保持附图 1 的表情、头部朝向、服装、姿态和背景。
面部阴影随本图光源调整，不直接复制附图 2 的光照。
```

**复查：**脸部是否可辨为同一人，头颈连接、表情和光线是否自然，其他角色有没有被误改。没有露脸的镜头无需补一张脸来证明一致。

### B. 地点变了，门窗或家具乱加

**先查：**机位在哪里？从入口向内看，还是从内部向外看？用稳定地标比较真实位置，而非只比较画面左右。

原案例有棚屋入口曾被做成门的历史修改记录。以下是对应的教学处理方式，不是一次已执行修复的还原：

```text
修正底图中的棚屋入口：恢复为设定中的开口，去掉新增的木门板和门框。
入口边缘及材料以所附已采用参考为准。
保留开口位置、视角、室内桌床关系和光线，不新增另一个出口。
```

**复查：**删除门后有没有留下不合理结构，室内布局是否被重排，下一镜是否仍能从同一位置观察。整体布局无法对应时，应先整理空间关系，再考虑重新生成。

### C. 关键道具不是同一件了

**先查：**故事需要“同款”还是“同一件”？哪些独特标记承担识别？原参考是否足够清楚？

《郊区网恋》将结尾裙装设定为前期礼物，但当前样式存在差异。应保留作者设定并记录视觉偏差，再选择统一到哪份参考，而不是让错误图片自动改变剧情。

```text
底图是结尾人物，参考图用于固定礼物裙装。
修正裙子的底色、印花组合、领口与版型，使其对应采用参考。
保持人物身份、姿态、所在位置和场景光线。
裙装褶皱与垂坠应适应当前身体和姿势，不直接复制参考图的平面形状。
```

**复查：**在前期和结尾实际展示大小下，是否仍能辨认关联。若参考之间本身冲突，先决定采用标准，再修改相关镜头。

### D. 文字、聊天界面或日期有误

先把正确文字、顺序、发送方和时间写成一份小表，确定内容再处理图像。不要让排字过程代替剧情决定。

| 内容       | 修改前必须明确                               |
| ---------- | -------------------------------------------- |
| 聊天消息   | 原文、发送方向、上下顺序                     |
| 日期和时间 | 绝对日期与“昨天”等相对时间是否对应           |
| 联系人     | 头像、公开昵称和备注是否有明确关系           |
| 交互状态   | 未回复、发送失败、拒收等分别需要什么可见依据 |

可以先尝试修正屏幕区域；对准确性要求高或反复失败时，采用后期排字或合成。处理方式取决于手头工具，不预设一次生成就能正确。

**案例边界：**原案例图中没有明确拉黑提示，不能只根据无人回复就写成“已经表现被拉黑”。若后续要补这个状态，先确认采用的叙事要求，再制作对应界面。

**复查：**逐字核对内容，再缩小到实际观看尺寸；同时检查手机开孔、边框、手指遮挡和屏幕透视，避免文字修好但设备变样。

### E. 比例错误或裁切会丢线索

先读取图片实际宽高。例如 1086 × 1448 是 3:4；目标若为 9:16，不能仅靠修改提示词记录完成。

以这组尺寸为例，保持高 1448 裁成 9:16，宽约为 815，会从左右合计去掉约 271 像素。这里只帮助估计损失，最终应按实际构图和工具尺寸约束选择。

处理顺序：

1. 标出人物、文字和线索不能被裁掉的区域。
2. 预览裁切，确认是否保留必要信息和空间关系。
3. 裁切不合适时，评估扩图或按目标比例重新生成。
4. 检查新尺寸、主体比例及新增区域，再更新采用文件。

不要直接横向压缩或纵向拉伸。扩图也可能新增不应出现的建筑或人物，需要重新检查边缘内容。

### F. 夜景发光、过度锐化或所谓“AI 味”

先把感觉拆成可见问题：光源不成立、阴影冲突、皮肤过于平滑、背景物件融合，还是风格与前后不一致？

```text
以附上的夜景图为底图，去掉桌面的自发光效果。
让桌椅只受道路路灯的微弱环境光照亮，轮廓仍可辨。
保留道路、桌椅位置、机位和地标，阴影随光源关系修正。
不新增光源，不把整张图压暗到看不清桌椅。
```

**复查：**光线更合理后，本镜任务是否仍完成。不要为追求手机质感叠加大量噪点和模糊，导致证据无法阅读。

### G. 多出牌子、人物或证件

先确认它是未经设计的新增，还是本来需要的物件。限制应该有范围。

例如原案例桌面火化证明属于有意设计的内容，不能因为其他镜头曾错误增加证件，就下达“删除所有证件”的全局要求。

```text
删除立牌旁新增的文字牌，仅修复该处被遮挡的背景。
保留人形立牌本身、桌椅、地面和观察角度。
不要把所有纸张或印刷物一并删除。
```

**复查：**删除区域是否自然，有无残留字形、重复纹理或错误遮挡；同时确认必要伏笔仍保留。

### H. 画面不错，关键意思却没表达出来

这是最容易被当成“再高清一点”处理的问题。先判断观众缺的是清晰度、识别依据，还是前文信息。

| 缺口                     | 修正方向                             |
| ------------------------ | ------------------------------------ |
| 关键特征太小或被挡       | 调整距离、构图、遮挡或增加特写       |
| 物件前后特征不同         | 对照采用参考修正身份特征             |
| 人物能认出，观众没有依据 | 提前建立识别特征，或安排必要叙述     |
| 缺少行动过渡             | 补镜头、转场或配文，并检查动机       |
| 结论本身缺少证据         | 回到构思和分镜，不能只靠锐化图片解决 |

原案例被子下的照片按作者设定拍的是主角。如果观众从未见过可识别的主角外貌，单纯提高照片清晰度仍可能不够。可考虑补充稳定的识别特征或简短叙述；这些是待选择的方案，不是已有图片已完成的效果。

## 5. 保存版本，再做三层复查

每次修改保留旧图，把新图作为候选。示例命名为 `Q02_v1.png`、`Q02_v2.png`，实际扩展名以文件格式为准。

复查分三层：

1. **目标问题：**原来的错误是否真的修好了？
2. **保留内容：**原本正确的身份、构图、光线和线索有没有漂移？
3. **前后关系：**新图接到相关镜头时，是否仍然连贯？

如果改动触及共用角色或场景参考，检查范围应扩大到依赖它的镜头。只修一处无关背景，不必无条件重做全片检查。

```text
问题 ID：
原文件与版本：
具体问题及影响：
采用的修正方式：
新文件与版本：
目标问题复查：
保留内容复查：
前后关系复查：
状态：待修改 / 待复查 / 已修正 / 接受保留
仍需处理的事项：
```

“已生成新图”只进入待复查状态。通过以后，再更新分镜采用文件、相关参考和图片链接。

## 6. 什么时候可以停下修改

没有必要追求每处垃圾纹理都相同。满足以下条件，就可以在注明范围内进入下一阶段：

- 关键行动、身份和线索可以被读懂。
- 与相关镜头的空间、时间和状态变化相容。
- 当前用途要求的比例、文字和后期处理已完成。
- 原本正确的关键内容没有被破坏。
- 仍保留的偏差有理由，且不阻断当前用途。

如果越改问题越多，先回到最近可靠版本，重新判断是描述冲突、参考错误、工具限制，还是分镜本身不合适。避免在持续漂移的图上无限追加指令。

接受保留的偏差仍是偏差，不需要把记录改写成“完全没有问题”。能进入剪辑或排版，也不等于最终发布检查已经完成。

## 7. 不知道下一步改什么时

可以把下面这段与图片、参考和当前分镜一起提交给能看图的工具：

```text
请先诊断，不直接修改图片。
本镜任务是：［填入任务］。
附图分别是：［底图与参考用途］。
我观察到的问题是：［具体差异］。

请判断：
1. 它是否真的违反设定，还是机位、遮挡或合理状态变化？
2. 对故事理解有什么影响？
3. 应局部编辑、后期处理、重新生成，还是修改分镜？
4. 修改时必须保留什么，完成后怎样检查？

资料不足的部分标为无法判断，不把猜测写成事实。
```
