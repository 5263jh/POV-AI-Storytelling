# 怎样与 AI 一起创作：从讨论到修改的对话指南

> 用具体任务推进创作，让已采用的决定、尚未采用的建议和实际图片结果始终分得清。

本指南配合[快速开始](quick_start.md)使用。快速开始带你完成一个片段，这里重点讲每一步怎样提出要求、判断回答是否有用，以及怎样接着做。

示例沿用《郊区网恋》第 21—24 镜的桌椅片段。对话是教学示例，不是原始聊天记录；涉及后续揭示的示例会注明剧透。工具能否看图、生成或编辑图片，取决于你实际使用的功能，不应仅凭对话中的承诺判断。

## 1. 每次说清当前要完成什么

一个请求可以包含四项：当前材料、当前任务、必须遵守的约束、希望得到的结果。没有必要每次复制完整世界观。

```text
当前材料：［相关设定、分镜或图片］。
这次任务：［讨论方案 / 写分镜 / 写提示词 / 生成 / 修改 / 检查］。
必须保持：［本次不能改变的内容］。
希望你给我：［具体输出］。
```

“你觉得下一张怎么做，先别做图”已经表达了明确任务。可以再补一句“给我两个方案，各说明它新增了什么信息”，让回答更便于比较。

讨论、生成和检查可以在同一段对话中进行，但每次要知道正在做哪一步。你明确要求生成时，不必再为普通执行细节反复确认；会改变剧情或关键设定的选择，应单独指出。

## 2. 开始时交代最少必要背景

第一次讨论一个片段，可以这样发：

```text
我们要设计一个连续图片片段，暂时不生成图片。

主角是考研生，经常骑车经过郊区的一条路。
他先在白天看到荒地里的旧桌椅，夜间再次经过时发现它们还在。
后来桌旁多出人形立牌，最后他靠近桌子，看见残败食物和爱心纸。

目标：从普通路边物件，逐渐产生有人刻意布置的感觉。
暂不揭示布置者，也不确认这是为主角准备的。
风格为手机摄影质感，9:16，主要采用主角第一视角。

请先检查这段顺序有什么因果或表达缺口。
区分已有内容和你的新增建议，不直接改成另一个故事。
```

有用的回答应指出具体问题，例如“从观察到坐下缺少选择过程”，并说明影响。只说“很有悬念”“很有代入感”，还不足以推进设计。

如果你不知道某个细节，就写“待定”。AI 提出的补充先当候选，不自动变成作者设定。

## 3. 讨论方案时，让差异清楚

以第三张出现立牌为例：

```text
前两张已经是白天发现桌椅、夜里再次看见。
第三张准备加入一个脏旧的虚构人形立牌，先别做图。

请给两个构图方案：
一个继续保持路上远观；另一个让主角已经停下，在路边观察。
分别说明观众能看清什么、是否提前透露太多、怎样接到靠近桌子的下一张。
最后推荐一个方案并说明理由，不增加布置者或解释性标语。
```

这里的“停下观察”是教学中的备选改编，不是原图已包含的事实。

选择时先看叙事任务：远观可以保留距离，靠近可以加强立牌的阅读。没有永远正确的角度，关键是这一张需要让观众获得什么。

采用后明确写一句：

```text
采用远观方案。保留原来的道路位置和桌椅关系。
第三张只让观众看出立牌有引导意味，不说明是谁摆的。
请整理成这一镜的简短分镜卡，不生成图片。
```

不必保存每一条未采用的意见，但要把最终决定写回分镜，避免后续重新混入被放弃的方案。

## 4. 从分镜得到可执行提示词

如果你准备自己把文字复制到图像工具，可以这样要求：

```text
请根据已经确定的第三张分镜写一份可直接提交的图片提示词。
包含视角、主体、地点关系、光线、需要保持的特征和必要限制。
本次只要提示词，不生成图片。

把背景剧情转成画面要求，不写“观众感到恐怖”来代替具体内容。
若有影响生成的未定项，请指出，不擅自决定关键设定。
```

检查输出是否真的描述了画面：立牌是印刷物还是人？桌椅在哪里？哪些细节应清楚？有没有同时要求远景和小字特写？

只保留本镜所需约束。全部故事、所有秘密、所有禁止项一起贴进去，容易产生互相冲突的要求。

详细字段可参考[单镜头提示词模板](../templates/shot_prompt_template.md)。

## 5. 提供参考图时，说明每张用来固定什么

不要只说“和之前一样”。明确附图、采用版本和参考范围：

```text
附图 1 是已采用的白天桌椅场景，用来固定道路、桌椅和远处地标。
附图 2 是立牌的造型参考，只采用印刷人物与破损边缘，不采用背景。

请生成第三张：白天，主角在道路上观察，桌旁新增立牌。
延续附图 1 的空间关系；立牌使用附图 2 的指定特征。
不复制附图 2 的机位，不加入真人或解释文字。
9:16，沿用已确定的手机摄影质感。
```

这个示例假定你确实拥有并提供了两张图。只有一张参考时，删除不存在的附件说明，改用文字描述新增物件。

发送前确认附件能被查看。若工具提示读不到图片，应重新提供可访问文件，或明确先按文字工作；不能把未看到的图片当作已核对依据。

多张参考有冲突时，指定采用哪部分。例如“桌子以图 1 为准，图 2 只参考立牌”。不要让“严格保持所有参考”成为无法执行的要求。

## 6. 生成后先看任务，再看细节

可以让能看图的 AI 帮你检查，但你仍需核对实际输出。将图片、分镜要求和参考一起提供：

```text
附图 1 是已采用的白天场景，附图 2 是这次生成的夜景。
请检查：是否能认出同一地点、桌椅是否一致、夜间光源是否合理。

请按以下格式列出问题：
具体观察 → 对照依据 → 对叙事的影响 → 最小修改建议。
看不清的地方标为无法判断，不补写画面里没有的信息。
这次只检查，不修改图片。
```

“看起来不错”不是验收记录。更有用的判断是“桌面出现自发光，与仅由路灯照明的设定冲突，可能改变观众对桌子的理解”。

同时防止误报：换机位导致左右变化、物件到了画外，都不一定是错误。要求检查者说明观察方向和依据，而不是只报差异。

## 7. 修改时指定底图、问题和保留内容

“不对，再做一张”可能让正确内容也发生变化。尽量描述可见问题：

```text
以本次附上的夜景图为底图。
问题是桌面自己发光，而设定中只有路灯照明。

修正桌面的发光效果，让桌椅受到微弱环境光照亮，轮廓仍可辨认。
保留道路、桌椅位置、机位和远处地标，局部阴影可随照明调整。
保持原比例，不新增灯或其他光源。
请执行这次修改。
```

“保留其他部分”表达的是修改目标，不是已经达到的保证。输出后对照检查，把新图存为新版本，不立即覆盖唯一的旧图。

比例有误时，先确认实际宽高和边缘内容。可以问“裁切会不会剪掉关键线索”，再决定裁切、扩图或重新生成，不要求单纯拉伸。

### 当修改开始影响整个场景

如果需要同时换机位、人物姿态和空间布局，先让 AI 说明影响范围：

```text
这次修改同时涉及机位和桌椅透视。
请先判断局部修改是否仍合适，或应以已采用参考重新生成。
列出各方案会影响哪些已确定内容，暂时不要改图。
```

选择方案后再执行。局部编辑和重新生成都是手段，目标是保住本镜任务及前后关系。

## 8. 发现设定被改写时，先纠正依据

下面的例子涉及《郊区网恋》后续剧情剧透。

原案例设定中，被子下的照片拍的是主角。但如果图片辨认不足，AI 可能把“看不清是谁”扩写成“身份未知”。可以这样纠正：

```text
作者已经确定：这些照片拍的是主角，请保留这一设定。
需要检查的是现有画面是否足以让观众认出主角。
请分开写作者事实、实际可见特征和表达不足，不把视觉不足改成新的剧情。
如果需要补充识别依据，给出建议并标为待采用。
```

反过来，也不要让 AI 把尚未确定的关系写成事实。例如原案例年长女性与棚屋主人的关系未确定，就不能因为道具组合而直接认定为母子或夫妻。

这类问题先改文档依据，再决定图片需不需要调整，避免在错误设定上继续生成。

## 9. 每做完一段，留下能继续工作的记录

不必整理所有聊天。保留这些内容通常就能减少下一次的重复沟通：

```text
本段采用的剧情与分镜版本：
人物、地点、道具的采用参考：
已采用图片及镜头对应关系：
实际提交的提示词：
已确认的修改决定：
尚未解决的问题及状态：
下一步准备做什么：
```

可以这样让 AI 整理：

```text
请整理本段制作交接记录。
只将我明确采用的内容列为已确定；其余分为建议和待定。
列出实际图片文件与版本，不编造文件名、参数或修复结果。
提出过修改但没有复查的项目，不要标为已完成。
```

整理后自己看一遍，再分别更新构思、设定、分镜和连续性记录。事后重写的提示词应标为教学重构或整理版，不冒充当时实际提交的原文。

## 10. 换对话或换工具时，重新交代当前状态

不要把继续工作的依据只放在“你应该还记得”上。向新对话提供简短记录和必要的原图：

```text
我们继续这个四镜片段。

目标：从远观桌椅，到发现有人刻意布置的意味。
当前已采用：Q01 和 Q02，图片已附上。
接下来做：Q03，白天桌旁新增污损的人形立牌。
固定要求：同一道路、同一组桌椅、9:16、主角第一视角。
暂不揭示：布置者身份。
待解决：从路边观察到坐下的行动衔接，暂不新增背景真相。

请先根据所附材料整理 Q03 的构图建议，不生成图片。
缺少必要资料时指出具体缺项，不假装已经看过未提供的图片。
```

文字摘要不能替代关键视觉参考。反过来，只提供图片而不说明采用范围，也可能让新工具把图片里的错误一起继承。

## 常见沟通卡点

| 遇到的情况               | 下一步怎样说                                           |
| ------------------------ | ------------------------------------------------------ |
| AI 只夸想法好            | “请指出最薄弱的一处因果，以及它会影响什么。”           |
| 一直讨论，却没有可用产出 | “采用刚才的第二方案，请整理成这一个镜头的最终分镜卡。” |
| AI 过早生成图片          | “当前只讨论构图，等我明确要求生成时再做图。”           |
| 提示词太长且重复         | “保留本镜任务、可见特征和必要限制，删除重复背景。”     |
| 新增内容抢走主线         | “将这些新增内容列为备选，当前采用版本不加入。”         |
| 图片有问题却说不清       | “先描述你看到的具体差异，暂不判断原因或改图。”         |
| 参考图没有被正确使用     | “说明每张参考实际用于哪些特征；无法查看的请标明。”     |
| 修改过后又产生新错误     | “比较新旧版本，分别检查目标问题和原本正确的关键内容。” |

如果请求无法执行，先确认原因是资料缺失、工具能力限制还是其他约束，再改用可行方案。未执行或未验证的工作应如实记录，不用文字承诺替代图片结果。
