# 故事设计指南：从一个脑洞到一段值得经历的故事

> 本指南讲怎样设计故事，再把它转成视觉叙事。主要例子来自《郊区网恋》，包含完整剧情和结局剧透。

一个荒地里的餐桌、一座奇怪的建筑、一段突然中断的聊天，都可以成为创作起点。但有了画面，还需要回答：谁被卷入？他为什么行动？行动改变了什么？最后，观众对这件事的理解发生了什么变化？

本指南提供一套可以试用、检查和调整的方法，不把某种题材的成功经验变成所有故事必须遵守的公式。没有反转、怪物或秘密身份，也可以讲好一个故事。

## 怎样使用这份指南

如果只有一个脑洞，先读第 1—3 节，写出人物、动机和因果。如果已经有完整剧情，重点检查第 4—8 节的信息、节奏和结尾。准备制作时，用最后的练习把想法整理到模板中。

文中的案例分为三类：

- **原案例设定与安排**：来自现有案例文档及镜头顺序。
- **案例中的表达问题**：作者已经确定，但现有图片未必充分表达的联系。
- **教学改进建议**：可考虑的修改方向，不代表原作品已经包含这些内容，也不自动改变原故事。

完整资料见[案例入口](../examples/suburban_online_romance/README.md)、[构思复盘](../examples/suburban_online_romance/idea.md)和[逐镜分镜](../examples/suburban_online_romance/storyboard.md)。这里的分析是事后整理，不声称所有细节都在出第一张图前规划完成。

## 1. 把脑洞放进一个人的生活

“荒地里有一张桌子”提供了一个值得看的画面，但还没有说明为什么要跟着某个人看下去。

可以依次补上四件事：

| 要素           | 要回答的问题                 | 《郊区网恋》的对应内容                   |
| -------------- | ---------------------------- | ---------------------------------------- |
| 人物与日常     | 他原本过着什么生活？         | 在城市边缘备考，上课、骑车、独自学习     |
| 在意的事情     | 什么让后来的变化有分量？     | 与兴趣相投的网友建立亲近关系             |
| 打断日常的变化 | 什么让原有生活无法照常继续？ | 关系中断；后来，常走路线旁出现桌椅布置   |
| 行动与后果     | 他做了什么，因此面对什么？   | 从经过、留意到靠近，逐渐进入一条引导路线 |

这些内容不必全部在开头解释，但作者需要知道它们怎样关联。

本案例的力量不只在桌椅有多奇怪，还在于它们后来与一段已经建立的感情经历连接起来。异常改变了人物对自己生活的判断。

### 现在可以写什么

```text
主角原本在过怎样的生活：
他目前想得到或保住什么：
什么变化打断了这种生活：
他因此采取什么行动：
行动让他面对什么新局面：
```

将答案合成一句话，再检查有没有只堆叠形容词。“诡异、震撼、神秘”可以描述目标气氛，但还不能代替事件和行动。

## 2. 让人物有理由继续

观众可以接受人物犯错，也可以接受他因感情、犹豫或冲动做出不明智的选择。需要讲清的是：从人物当时的处境看，他为什么这样选？

不要只用“他很好奇”解释所有深入危险的行为。好奇足以支持路过时看一眼，是否足以支持进入陌生人的住处，需要另行判断。

把关键选择拆成五项：

```text
人物当时知道什么：
他想获得或避免什么：
他认为继续行动的风险是什么：
他还有什么选择：
为什么此刻选择这一条：
```

这里的风险是人物当时能够判断的风险。作者知道棚屋主人的身份，不等于主角在看到第一张桌子时也知道。

### 案例：从路过到进入棚屋

《郊区网恋》中，通学路线让主角反复经过荒地有了日常依据。桌椅持续存在、立牌出现、前方还有桌子，使观察逐渐变成探索。

但“为什么坐到桌边”“为什么最终进入棚屋”仍是需要检查的行动节点。现有图片省略了部分选择过程；不能只因为后面需要揭示真相，就认定这些选择已经充分成立。

**教学改进建议：**在改编或修订时，可以考虑更清楚地表现主角当下注意到的邀请线索，或补充一句符合人物处境的叙述。如果新增某个与网恋有关的识别物，又会提前暴露两条线的关系，应一起调整信息顺序。

补动机不是为每个动作加一段解释。只补会让观众问“他为什么突然这样做”的关键跳跃。

## 3. 用选择和后果连接事件

先用最简单的句子写出一段：

> 因为发生了什么，人物选择做什么，因此局面怎样变化？

这个句式用于找缺口，不要求所有镜头都单独制造一个结果。建立环境、表现等待和承接情绪的镜头，也可以服务于一个较长的因果段落。

### 案例里的两条线

| 线索段落 | 原案例中的发展                             | 设计上要检查什么                             |
| -------- | ------------------------------------------ | -------------------------------------------- |
| 线上关系 | 交流产生亲近，赠送礼物，提出见面，失去回应 | 信任和失落有没有建立，而不只是聊天截图堆叠？ |
| 荒地探索 | 看见桌椅，再次留意，发现引导，靠近并深入   | 每次继续的理由是什么，空间是否接得上？       |
| 两线汇合 | 礼物、照片和真人出现，让前文获得新的解释   | 哪些可见特征真正连接了线上与现实？           |

原案例作者设定中，账号实际使用者接收礼物、观察主角，并布置路线。这解释了为什么两条线相连。但“作者已有解释”还需要经过视觉表达，才能成为观众能读出的联系。

### 查找巧合的位置

偶然事件可以成为开端。问题通常出现在：越到解决关键矛盾时，越依赖此前毫无依据的新人物、新能力或新文件。

检查结尾的关键解决方式：它是否由前面的行动、人物能力或规则支持？如果删掉最后突然出现的帮助，人物此前的选择是否仍有作用？

发现缺口时，可以提前建立必要条件，也可以改变解决方式。不要为了让结尾成立，临时补一个没有限制的新规则。

## 4. 决定观众关心什么，以及何时改变理解

“想知道答案”只是观看动力之一。观众也可能想知道一个目标能否实现、一段关系能否继续，或人物会怎样选择。

| 关注方向 | 设计时可以问                                   |
| -------- | ---------------------------------------------- |
| 目标     | 他能否完成？阻碍是什么？失败意味着什么？       |
| 关系     | 双方想要的是否一致？什么行动会改变彼此的信任？ |
| 谜题     | 哪些解释目前成立？什么线索会让它们不再足够？   |
| 选择     | 两个选项分别要付出什么代价？人物愿意失去什么？ |

一个故事可以包含几种动力，但应知道当前段落主要依靠哪一种。

### 案例：让问题发生转移

《郊区网恋》前期可以让观众关心关系为什么中断；荒地段落转向桌椅是谁摆的、路线通往哪里；进入棚屋后，两类问题逐渐相接。

不必一开始就宣布“我们要查出账号背后是谁”。否则前期的关系体验可能变成单纯等着揭穿骗局。是否这样处理，是创作选择，需要与作品想给人的经历一致。

可以用下面的表安排知识变化：

| 段落     | 人物掌握的信息 | 观众实际获得的内容   | 希望形成的理解 | 仍然保留的问题 |
| -------- | -------------- | -------------------- | -------------- | -------------- |
| ［段落］ | ［已知与误解］ | ［画面、文字或声音］ | ［预期推断］   | ［未解部分］   |

第一视角也不保证人物与观众知道得一样。人物可以立即认出自己的照片，观众却可能此前从未见过他的脸。

## 5. 设计伏笔时，先找事实会留下什么痕迹

对悬疑故事，可以先写下关键事实，再推导它会在人物行为、物件或环境中留下什么。

```text
作者确定的事实：
这个事实会留下什么痕迹：
痕迹为什么会出现在这里：
人物怎样接触到它：
观众初见时可以怎样理解：
后来什么信息会改变这个理解：
```

这样做的目的，是让线索属于故事世界，而非只为结尾服务的标记。普通物件也可以只是普通物件，不需要全部承担伏笔。

### 案例：礼物的含义变化

| 出现阶段           | 叙事作用                       | 执行要求                                     |
| ------------------ | ------------------------------ | -------------------------------------------- |
| 购买礼物           | 关系从聊天发展为实际投入       | 让观众有机会记住必要特征                     |
| 对方发送裙子照片   | 让赠送行为得到回应             | 保持礼物可对应，并注意照片不能验证操作者身份 |
| 假人配饰、结尾裙装 | 将线上经历连接到现实空间和人物 | 必须能与前期道具建立足够清楚的联系           |

礼物前期意味着亲近，后期成为身份与距离发生变化的依据。同一对象的含义可以变化，对象本身却需要保持可辨认。

**案例中的表达问题：**当前结尾裙装与前期图片存在样式差异。作者设定为同一件礼物，并不等于成图已充分完成回收。具体问题见[连续性记录](../examples/suburban_online_romance/continuity_notes.md)。

### 分清线索和结论

爱心餐桌能提示感情意味，不能独自证明它与某个账号有关；工作用品能提示劳动背景，不能单独确定账号身份。几条线索需要怎样组合，才支持你希望观众形成的结论？

不强制使用固定数量的证据。少量清楚且相互支持的线索，可能已经足够；数量很多但无法辨认，也不能自动加强结论。

## 6. 节奏靠变化和停留共同形成

节奏不等于越来越快，也不等于每张图都比上一张更吓人。先问当前段落在做什么，再决定停留多久、拆几张图。

《郊区网恋》的日常段落用于建立人物、路线和交流情境；关系中断后回到做题，让生活暂时平缓；荒地探索再把注意力引向现实异常。

这不意味着其他故事需要同样长的开场。每张日常图都应有具体作用，不能用“建立真实感”替所有重复辩护。

### 判断重复是否值得保留

以第 21—23 镜为例：

- 第一次看见桌椅：它可以被理解为路边弃物。
- 夜间再次看见：持续存在开始获得意义。
- 后来出现立牌：人为引导的意味增强。

重复的对象保留了，信息发生变化。但这些变化是否足够清楚，仍要看画面中的地点识别、昼夜和新增物件。

```text
这几张共同承担什么任务：
每张增加或保留了什么体验：
删去其中一张会损失什么：
有无因构图或文字太相似而难以读出的变化：
决定保留、合并或调整的原因：
```

聊天记录和照片往往需要阅读时间。静态图文中读者可以停留；转成视频后，要实际观看并调整时长，不能只按统一秒数处理。

## 7. 让结尾回应前面建立的期待

先写一个问题：观众走到这里，最需要看到什么得到回应？

可能是找到某个人、完成一件事、作出一个选择，也可能是理解此前误会。结尾可以温暖、失败、平静或开放，不必为了冲击追加一个反转。

### 案例：真人出现为何需要前文

《郊区网恋》选择先展示空间和生活痕迹，再展示被子下的主角照片，最后让男人穿着礼物裙装出现。

最后一镜同时提供新的真人形象，并让前文线索汇合。如果删掉前面的联系，它可能只剩“一个陌生人出现在棚屋外”，无法承担原本的身份揭示。

也不要把效果完全押在“观众绝对猜不到”。有人提前怀疑账号身份，仍可能关心猜测怎样成立、人物将面对什么。

本案例的威胁来自身份欺骗、跟踪和引导。人物的体型、职业或穿裙子本身不能代替这些行为成为叙事原因。

### 留白需要划定范围

| 应优先讲清的主线             | 可以保留的次级背景           |
| ---------------------------- | ---------------------------- |
| 线上对象与现实人物如何关联   | 年长女性与棚屋主人的具体关系 |
| 这些照片为什么对主角构成威胁 | 对方完整的个人经历           |
| 礼物和路线为何与此前关系有关 | 所有行为发生的精确起始时间   |

右列在原案例中尚未确定或未揭示，不能擅自写成母子、夫妻关系或完整身世。留白可以保留余味，但不能要求读者先猜中未提供的背景，才能理解主线。

## 8. 用检查找出故事薄弱处

写完后，先暂时不看世界观说明，只读准备给观众的画面、正文和声音安排。按以下问题检查：

| 常见问题               | 识别方法                           | 可以尝试的调整                           |
| ---------------------- | ---------------------------------- | ---------------------------------------- |
| 有脑洞，人物却无关紧要 | 换成任何主角都不影响行动和后果     | 明确人物在意的事与异常之间的关系         |
| 主角只是在执行作者安排 | 到关键节点只能解释“剧情需要他进去” | 补当时的信息、动机或选择；必要时改行动   |
| 事件只是排列           | 段落间只剩“然后又出现一个东西”     | 检查前一选择是否改变下一局面             |
| 反转没有依据           | 只有结尾说明才首次给出全部关键事实 | 提前建立必要条件，或调整结论范围         |
| 线索很多但主线不清     | 每个物件都引出独立谜团             | 减少无关线索，明确主要回收关系           |
| 作者知道，观众认不出   | 结论依赖未露过的脸或不一致的道具   | 增加辨认依据，修正成图，或安排必要叙述   |
| 故意藏信息变成无法理解 | 观众连人物为什么行动都不知道       | 提供行动所需信息，保留更深层答案         |
| 结尾解释过量           | 核心问题已经回应，仍继续逐件讲背景 | 保留理解主线必要的解释，次级内容另行安排 |

每次先修影响理解最大的一个问题。补一个线索可能改变悬念，删一张图可能破坏空间，所以修改后再顺序读一遍相关段落。

### 如果请别人试读

先让对方看到准备发布的内容，不先解释后台设定。可以问：

1. 你认为发生了什么？
2. 哪个画面或句子让你这样理解？
3. 哪一步你没跟上，或觉得人物行动突然？
4. 结尾回答了什么，还有什么没明白？

记录具体反馈和对应版本。读者给出不同解释，不一定就是设计失败：先判断它是否影响核心目标，再决定是否修改。没有进行试读时，不把预期反应写成测试结果。

## 9. 把设计写成下一步能用的材料

读完后，可以先完成下面这一页，不急着把所有设定填满：

```text
故事名称：
一句话概念：
主角想得到或保住什么：
打断日常的变化：
最重要的一次选择及理由：
这次选择带来的后果：
结尾回应什么：

作者已经确定的关键事实：
仍待决定、会影响制作的问题：
准备让观众看到的关键依据：
哪些理解需要配文、对白或旁白：
可保留的未知：

目前最薄弱的一环：
准备怎样检验或修改：
```

随后根据需要继续：

| 当前任务                           | 下一份文件                                               |
| ---------------------------------- | -------------------------------------------------------- |
| 完整整理构思                       | [故事构思模板](../templates/story_idea_template.md)      |
| 固定需要重复使用的人物、地点和道具 | [故事设定模板](../templates/story_bible_template.md)     |
| 决定每张图的内容和顺序             | [分镜模板](../templates/storyboard_template.md)          |
| 把某张分镜转成生成或修改要求       | [单镜头提示词模板](../templates/shot_prompt_template.md) |
| 核对实际图片与修订结果             | [连续性检查清单](../templates/continuity_checklist.md)   |

可以先把会影响下一段制作的内容想清楚，再继续细化。创作中出现更好的选择时，更新相关设定和分镜，保留修改理由；不必把第一版构思当成永远不能改变的答案。
